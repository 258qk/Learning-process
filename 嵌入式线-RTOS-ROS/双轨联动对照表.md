## 逐月细节对照

### 阶段一：打地基（M1-M3）

| 月份 | AI 线                             | 嵌入式线                           | 联动点                           |
| ---- | --------------------------------- | ---------------------------------- | -------------------------------- |
| M1   | Python基础语法 + NumPy + Matplotlib | STM32外设复习：GPIO/定时器/中断/UART/I2C/SPI/ADC | NumPy 模拟的传感器数据 = MCU 真实采到的数据，两边对照理解 |
| M2   | Pandas + Linux命令行 + 数学复习     | CAN总线 + 编码器 + SD卡 + 综合采集终端 | AI 线的 `sensor_data.csv` 格式 = 嵌入式线 SD 卡记录的格式 |
| M3   | PyTorch入门：Tensor/autograd/CNN    | FreeRTOS入门：任务/队列/信号量/互斥量 | 理解"实时调度"概念有助于理解 PyTorch DataLoader 的多进程 |

**本阶段总结**：两条线完全独立，各打各的基础。AI 线在 PC 上学数据，嵌入式线在板子上学控制。

---

### 阶段二：深度学习 + RTOS 深化（M4-M6）

| 月份 | AI 线                             | 嵌入式线                           | 联动点                           |
| ---- | --------------------------------- | ---------------------------------- | -------------------------------- |
| M4   | CNN深入：VGG/ResNet/YOLO             | FreeRTOS深入：内存管理/中断/Trace   | FreeRTOS 的优先级抢占 = CNN 层的优先级（浅层特征→深层语义） |
| M5   | RNN/LSTM + Transformer               | Linux入门：Buildroot/字符驱动/设备树 | AI 线开始碰 Linux 训练环境，嵌入式线开始碰 Linux 系统 |
| M6   | BERT/GPT + 论文复现                  | Linux多线程/网络编程 + ROS2初探      | 嵌入式线的 ROS2 环境直接跑在 AI 线装的 Ubuntu 上 |

**本阶段总结**：两条线开始有交集——都需要 Linux 环境。AI 线的训练脚本跑在服务器，嵌入式线的 ROS2 跑在同一台机器的另一个终端。

---

### 阶段三：★ 双轨交汇 ★（M7-M9）

| 月份 | AI 线                             | 嵌入式线                           | 联动点                           |
| ---- | --------------------------------- | ---------------------------------- | -------------------------------- |
| M7   | 模型导出：ONNX/TorchScript           | ROS2：传感器消息/TF2/Nav2导航/融合   | **开始对接**：把 AI 线导出的 ONNX 模型传给嵌入式线 |
| M8   | TensorRT部署 + NCNN + 量化剪枝       | Jetson刷机 + TensorRT+NCNN 实战      | **完全同步**：两边学同一个东西（TensorRT/NCNN），只是分工不同 |
| M9   | 模型压缩理论深化                     | **端到端项目**：训练→ONNX→TensorRT→Jetson实时检测 | **交汇完成**：产出第一个"AI+嵌入式"完整项目 |

**本阶段总结**：两条线在 M8 完全合流——AI 线负责"怎么训练出更小更快的模型"，嵌入式线负责"怎么把模型跑在板子上"。合在一起就是一个完整的嵌入式 AI 项目。

---

### 阶段四：LLM + 行业交叉（M10-M13）

| 月份 | AI 线                             | 嵌入式线                           | 联动点                           |
| ---- | --------------------------------- | ---------------------------------- | -------------------------------- |
| M10  | LoRA/QLoRA 微调                     | ROS2高级：生命周期/launch/PX4+视觉   | 嵌入式线的视觉处理 = AI 线训练的分类/检测模型 |
| M11  | RAG管道：LangChain + 向量数据库      | STM32 + 4G（MQTT上云）              | LLM 的推理可以跑在云端，嵌入式端通过 MQTT 调用 |
| M12  | Agent开发                           | STM32 + BLE/WiFi                    | Agent 控制硬件（如"Agent 控制无人机起飞"） |
| M13  | 行业交叉项目（三选一）              | 行业交叉项目（三选一，同选一项）     | **共建同一个项目**：AI 线做算法，嵌入式线做工程 |

**三项目分轨对照**：

| 项目             | AI 线角色                            | 嵌入式线角色                      |
| ---------------- | ------------------------------------ | -------------------------------- |
| 无人机视觉避障   | 训练YOLO检测模型 + 强化学习策略        | Gazebo仿真 + PX4 Offboard + ROS2  |
| 通信信号识别     | 训练CNN/Transformer调制识别模型       | STM32采集RF + 串口→Linux→推理回传 |
| GNSS误差预测     | 训练LSTM误差预测模型                  | RTK模块 + IMU + ROS2定位融合      |

**本阶段总结**：到 M13，你不再是一个"会 Python 的 AI 调参侠"，也不是一个"只会单片机的外设驱动工程师"——你是能一个人搞定"算法设计 + 端侧部署 + 系统集成"的完整方案工程师。

## 时间分配建议

| 时段            | AI 线             | 嵌入式线           | 总计     |
| --------------- | ----------------- | ------------------ | -------- |
| 工作日（周一~五）| 3h/天             | 1~1.5h/天          | 4~4.5h/天 |
| 周末（周六）     | 4h（深度学习攻坚） | 3h（硬件项目）      | 7h       |
| 周末（周日）     | 2h（复习+GitHub）  | 1h（复盘）          | 3h       |

| 维度         | 每周总计        |
| ------------ | --------------- |
| AI 线        | 21h（3×5 + 4 + 2） |
| 嵌入式线     | 10~12.5h         |
| **总计**     | **31~33.5h/周**   |

> ⚠️ 这个量属于"高强度"档。如果感到吃力，优先保 AI 线（这是三个行业 AI 岗的敲门砖），嵌入式线可以压缩到工作日 30min/天。

## 关键风险提示

| 风险                          | 应对                                                            |
| ----------------------------- | --------------------------------------------------------------- |
| M7-M9 交汇阶段工作量暴增       | 两条线学同一个东西（TensorRT/NCNN），实际是同一份学习内容分两边看 |
| 硬件采购拖延导致嵌入式线卡住   | M1-M4 最低只需 STM32 开发板（~150元）；仿真可替代大部分实操      |
| 嵌入式线占用时间影响 AI 线进度 | M6 之后嵌入式线的内容（ROS2/Linux）和 AI 线高度重叠，一鱼两吃     |
| 精力过载 burnout              | 每周至少一天轻量日；每完成一个阶段奖励自己一天休息                |
