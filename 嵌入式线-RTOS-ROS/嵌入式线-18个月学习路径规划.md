# 嵌入式线 — 18个月学习路径规划

> **定位**：与 AI 线（`00-规划与参考/18个月三行业AI工程师学习路径规划.docx`）**并行推进**的嵌入式系统学习线。
>
> **目标**：从 51/STM32 入门基础 → RTOS 精通 → Linux 嵌入式开发 → ROS2 机器人开发 → 嵌入式 AI 部署全链路。
>
> **与 AI 线的分工**：
>
> | AI 线（3h/天）       | 嵌入式线（额外时间/天）       |
> | -------------------- | ----------------------------- |
> | 算法原型 + 训练      | MCU / RTOS / Linux / ROS       |
> | Python / PyTorch      | C / C++ / 嵌入式工具链         |
> | 云端训练 + 模型设计   | 端侧部署 + 硬件适配            |
>
> **两线交汇点**：M7-M9（模型部署阶段），AI 线训练出的模型 → 嵌入式线部署到端侧。

## 四、18 个月分阶段学习路径

---

### 阶段一（M1-M3）：MCU 深化 + RTOS 入门

> **并行状态**：AI 线正在学 Python/Numpy/PyTorch 入门
> 
> **本阶段目标**：从"能写单片机外设驱动"到"能用 RTOS 管理多任务"，建立实时系统思维。

#### 第 1 个月：STM32 外设系统复习 + 提高

| 周次 | 学习内容 | 每日任务（约 1-1.5h）        | 周产出                           |
| ---- | -------- | ---------------------------- | -------------------------------- |
| 第1周 | GPIO/定时器/中断 深度练习 | 用寄存器操作 GPIO（不用 HAL）；定时器 PWM 输出控制舵机；外部中断响应按键 | 舵机控制程序（PWM + 中断） |
| 第2周 | 串口通信（UART/DMA） | 阻塞式→中断式→DMA 式 UART 收发，三种方式对比；环形缓冲区实现 | 串口命令行调试框架（类似 Shell） |
| 第3周 | I2C / SPI 通信 | I2C 读写 EEPROM/OLED；SPI 读写 Flash；对比两种协议时序 | OLED 屏幕驱动 + 显示传感器数据 |
| 第4周 | ADC/DAC + 传感器实战 | ADC 多通道采集（DMA）；IMU（MPU6050）数据读取+姿态解算 | 6 轴 IMU 数据采集+串口可视化 |

#### 第 2 个月：通信协议深化 + 项目实战

| 周次 | 学习内容 | 每日任务          | 周产出                           |
| ---- | -------- | ----------------- | -------------------------------- |
| 第5周 | CAN 总线 | CAN 协议原理；CAN 收发器配置；双板 CAN 通信 | 双 MCU 通过 CAN 互发传感器数据 |
| 第6周 | 定时器高级应用 | 输入捕获（测频率/占空比）；编码器接口；多路 PWM 同步 | 编码器测速 + PID 速度闭环 |
| 第7周 | 文件系统 + SD 卡 | FATFS 移植；SD 卡 SPI 模式读写；CSV 数据记录 | 传感器数据记录仪（CSV 存 SD 卡） |
| 第8周 | 综合项目：数据采集终端 | 整合前 7 周知识 | 多传感器数据采集终端：IMU+温度+GPS → SD 卡记录 + 串口输出 |

#### 第 3 个月：RTOS 入门（FreeRTOS）

| 周次 | 学习内容 | 每日任务          | 周产出                           |
| ---- | -------- | ----------------- | -------------------------------- |
| 第9周 | RTOS 概念 + 任务创建 | 前后台 vs RTOS 区别；FreeRTOS 移植到 STM32；vTaskCreate 创建 3 个闪烁任务 | 3 任务 LED 不同频率闪烁 |
| 第10周 | 任务调度 + 队列 | 优先级抢占；任务状态转换；`xQueueSend/Receive` 任务间通信 | 生产者-消费者数据流（传感器采集→处理→输出） |
| 第11周 | 信号量 + 互斥量 | 二值信号量（任务同步）；计数信号量（资源管理）；互斥量（共享资源保护） | 多任务共享 OLED 屏幕（互斥锁保护） |
| 第12周 | 软件定时器 + 低功耗 | FreeRTOS 软件定时器；Tickless 低功耗模式；任务通知 | RTOS 版传感器采集终端（替换前后台版本） |

### 阶段二（M4-M6）：RTOS 深化 + Linux 入门

> **并行状态**：AI 线正在学 CNN/RNN/Transformer 深度学习
> 
> **本阶段目标**：FreeRTOS 精通 + 进入 Linux 嵌入式的世界。

#### 第 4 个月：FreeRTOS 深入

| 周次 | 学习内容 | 每日任务          | 周产出                           |
| ---- | -------- | ----------------- | -------------------------------- |
| 第13周 | 内存管理 + 中断管理 | heap_1~heap_5 对比；中断中调用 FreeRTOS API 的规则（FromISR） | 使用事件组实现多事件同步 |
| 第14周 | 任务通知 + 流缓冲区 | 任务通知替代信号量（更快）；流缓冲区传输不定长数据 | 高速数据流传输 + 处理管道 |
| 第15周 | 调试 + Trace 分析 | FreeRTOS 运行时统计（`vTaskGetRunTimeStats`）；Segger SystemView 使用 | CPU 使用率分析报告：哪个任务占了多少时间 |
| 第16周 | 综合项目 | 整合阶段一+二的 FreeRTOS 知识 | RTOS 四轴飞控基础：姿态读取任务(1kHz) + PID控制任务(500Hz) + 通信任务 + 日志任务 |

#### 第 5 个月：嵌入式 Linux 入门

| 周次 | 学习内容 | 每日任务          | 周产出                           |
| ---- | -------- | ----------------- | -------------------------------- |
| 第17周 | Linux 系统基础 | Bootloader→Kernel→RootFS 启动流程；Shell 常用命令强化（grep/awk/sed/find） | 用脚本自动解析 MCU 串口输出的 CSV 数据 |
| 第18周 | Buildroot 构建系统 | Buildroot 配置 + 编译；裁剪最小 Linux 系统；烧录到开发板 | 为 STM32MP1/Raspberry Pi 编译最小 Linux 镜像 |
| 第19周 | Linux 驱动基础 | 字符设备驱动框架；`file_operations` 结构体；`insmod/rmmod` | 写一个最简单的字符设备驱动（Hello World 驱动） |
| 第20周 | 设备树 + GPIO 驱动 | 设备树语法（`.dts`）；GPIO 子系统；`gpiod` API | 用设备树配置 LED → 写 GPIO 驱动 → 用户空间控制 |

#### 第 6 个月：Linux 应用开发 + ROS2 初探

| 周次 | 学习内容 | 每日任务          | 周产出                           |
| ---- | -------- | ----------------- | -------------------------------- |
| 第21周 | Linux 多线程编程 | `pthread` 创建/join；互斥锁/条件变量；对比 FreeRTOS 任务 | Linux 版多线程传感器采集（对标 FreeRTOS 版） |
| 第22周 | Linux 网络编程 | Socket（TCP/UDP）；epoll 多路复用；简单 HTTP 服务器 | 传感器数据 TCP 服务器（接收端+显示端） |
| 第23周 | ROS2 核心概念 | Node/Topic/Service/Action；`rclcpp` 写第一个 Node；`ros2 topic` 命令行 | 用 ROS2 Topic 发布传感器数据 |
| 第24周 | ROS2 + Gazebo 入门 | Gazebo 安装+基本操作；URDF 机器人模型；ROS2 控制 Gazebo 中的机器人 | 在 Gazebo 中启动一个带传感器的移动机器人 |
