# 学习会话记录

此 skill 用于在每次学习会话结束后，记录当天的对话框架和重要上下文。目的是在新会话开始时快速恢复状态，不依赖完整的对话历史。

## 与"进度记录.md"的区别

| 进度记录.md | 学习会话记录（本文件） |
|------------|---------------------|
| 记录学习内容、时长、代码产出 | 记录对话框架、重要决策、用户偏好 |
| 数据导向（时间、代码量） | 上下文导向（说了什么、决定了什么） |

## 记录格式

每次学习结束后，追加以下内容到 `00-规划与参考/学习笔记/会话记录.md`：

```
## 第 X 次学习 — YYYY-MM-DD（周X）

### 对话大纲
1. （第一个话题）
2. （第二个话题）
   ...

### 重要决策 / 共识
- （用户决定的事项、约定的规则等）

### 用户新偏好 / 发现
- （用户反馈的习惯、风格偏好等）

### 当前进度状态
- 阶段：阶段一（M1-M3）
- 已完成：Day 0X 完成
- 下一个里程碑：XX项目
- 进度百分比：总进度 X%

### 下次计划
- （预定的下次学习主题）
```

## 会话记录文件路径
`00-规划与参考/学习笔记/会话记录.md`
