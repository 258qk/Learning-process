# 困难知识总结

记录学习过程中遇到的难以理解的知识点，便于复习回顾。

| 日期 | 知识点 | 困难描述 | 理解思路 | 解决方法 |
|------|--------|---------|---------|---------|
| 2026-06-07 | Python `for i in list` vs C `for(i=0;i<n;i++)` | 用 C 思维写成 `data_2[i] += 10`，但 `i` 是元素值而非下标，导致逻辑错误或越界 | Python 的 `for item in list` 遍历的是值，不是下标。需要下标时用 `for i in range(len(list))` 或 `for i, val in enumerate(list)` | 对比两种写法，理解每种适用场景：<br>• 只需值 → `for x in arr`<br>• 需下标 → `for i in range(len(arr))`<br>• 都需要 → `for i, x in enumerate(arr)` |
| 2026-06-08 | Python 列表切片 `[-n:]` vs `[0:-n]` | 想取最后 4 个元素写成了 `arr[0:-4]`，实际取出的是前 6 个 | `[a:b]` 是下标 a 到 b-1。`[-4:]` 表示"从倒数第4个取到末尾"；`[0:-4]` 表示"从开头取到倒数第4个（不含）" | 取最后n个 → `arr[-n:]`；丢弃最后n个 → `arr[:-n]` |
| 2026-06-08 | linspace 步长陷阱 | Python 手写 linspace 时用 `i * 2π / N`，最后一个点不等于终点值 | `linspace(起点, 终点, N)` 有 N 个点、N-1 个间隔。步长 = `(终点-起点)/(N-1)` 而非 `/N` | 类似 C 里数组下标差 1 的 off-by-one 错误 |
| 2026-06-08 | `np.mean(list)` 为什么能接收 Python 列表 | 以为 `np.mean()` 是 ndarray 的方法，疑惑为什么传入普通列表也能用 | `np.mean()` 是 NumPy 的**函数**（不是方法），接收任何数组类参数，内部自动做 `np.array(data)` 转换 | `np.mean(list)` ≈ `np.array(list).mean()`，NumPy 函数自动转换；但 `list.mean()` 不存在——列表没有这个方法 |
| 2026-06-08 | axis 方向判断 | reshape 后对 axis=0 和 axis=1 求均值，容易搞反方向 | axis=0 = 上下方向（列），axis=1 = 左右方向（行）。像 C 里的二维数组：axis=0 是第一维，axis=1 是第二维 | `arr.sum(axis=0)` = 沿着行方向求和（每列一个结果）；`arr.sum(axis=1)` = 沿着列方向求和（每行一个结果） |
